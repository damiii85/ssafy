# SPOT CHECK

대구 다섯 권역의 상가정보·PDF를 검색하고 주소 반경 점포 수와 지역 통계를 근거와 함께 제공하는 RAG 서비스입니다.

## 압축 해제 후 실행

**실제 CSV·PDF·검색 벡터가 포함되어 있습니다. 재수집·임베딩 생성 없이 실행할 수 있습니다.**

1. ZIP 전체를 원하는 폴더에 압축 해제합니다.
2. Python 3.11이 설치된 Windows에서 프로젝트 루트의 `실행.bat`을 더블클릭합니다.
3. 최초 실행에서 의존성을 설치하고 포함된 벡터를 로컬 DB에 자동 복원합니다. 이때 임베딩 API를 호출하지 않습니다.
4. 브라우저에서 `http://localhost:8501`을 엽니다.

최초 패키지 설치와 지도 타일 표시는 인터넷 연결이 필요합니다. Windows/Python 3.11 환경을 기준으로 준비했습니다.

**API 키 없이도 지역 선택·CSV 집계·주소 반경·PDF 답변·로컬 벡터 검색이 동작합니다.** 키 없는 실행에서는 GPT를 호출하지 않습니다. 네이버 키가 없으면 인증 없는 기본 지도로 기준점을 표시합니다.

GPT-6 Luna를 사용하려면 실행 도구가 만든 프로젝트 루트의 `.env`에 **받는 사람 본인의 GMS_API_KEY**를 넣고 서버를 다시 실행합니다. 키가 있으면 GMS 모드, 없으면 로컬 모드를 자동 선택합니다. GMS 모드에서는 질문·메타데이터·PDF 발췌가 GMS로 전송되며 호출 비용이 발생합니다. 실제 API 키는 제출물에 포함하지 않습니다.

| 키 | 사용처 |
|---|---|
| GMS_API_KEY | GPT-6 Luna 검색어 생성·후보 평가·원문 발췌 및 GMS 질의 임베딩. 없으면 로컬 모드 |
| NAVER_MAP_CLIENT_ID | 네이버 지도와 등록 도메인 설정. 없으면 기본 지도 |
| PUBLIC_DATA_API_KEY | 신규 수집 시에만 필요. 제출본 실행에는 불필요 |
| TAVILY_API_KEY | 별도 웹 수집 CLI에서만 필요 |

수동 실행:

```powershell
cd aiproject2
py -3.11 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
.venv\Scripts\python.exe scripts/verify_package.py
.venv\Scripts\python.exe -m streamlit run app.py
```

이미 `.env`가 있으면 덮어쓰지 않습니다. 실행 창에서 Ctrl+C로 서버를 종료합니다. 포트 충돌 시 `--server.port 8503` 등으로 바꿀 수 있습니다.

## 필수 기능과 심화 기능

지원 권역: 대구 도심 통합상권(동성로·대구역·반월당), 수성못, 삼덕동, 동대구역, 칠곡3지구.

| 요구사항 | 기능 |
|---|---|
| F2001~F2002 | 상권·업종 정보 적재, Chroma 색인, 중복 방지 |
| F2003~F2005 | GMS 모드의 검색어 생성·PDF 후보 평가, 문서 청킹·색인 |
| F2006~F2008 | 두 컬렉션 검색·필터·중복 제거, LangGraph retrieve/generate, 원문 검증·근거 번호 |
| F2009 | 지역별 대화·세션 내 기록·새 대화와 보관 기록 복원 |
| F2010 | 등록 주소·기준점의 실제 좌표 거리 집계와 지도·차트 |
| F2011 | 지역·업종·등록 점포 수 조건의 지원 지역 탐색 |
| F2012 | 진행·자료 부족·연결 실패 안내, 사용자 메시지 선표시와 AI 로딩 |

F2004는 지정 PDF 후보를 평가하고 선택된 문서만 색인 확인·추가한 뒤 document_id 필터로 검색 범위를 제한합니다. 선택 지역의 설명 문서는 필수 보존하며 모델 호출 실패 시 지역 문서를 사용합니다. 다른 질문에서 사용하는 기존 문서는 전역 삭제하지 않습니다. 기본 서비스는 질문마다 웹이나 상가 API를 새로 수집하지 않습니다.

선택 심화는 **F2015 전후 품질 비교**입니다. 동일 GPT-6 Luna와 대표 질문 5개로 무검색/실제 서비스 응답을 확보하고 사실 정확성·근거 제시·기권을 평가했습니다. 검색어 호출 실패 후 대체 응답도 포함했습니다. CSV 계산·PDF 직접 해석이 함께 포함되어 순수 검색 문맥만의 효과를 분리한 실험은 아닙니다. F2013·F2014·F2016은 미선택입니다.

## 데이터와 색인

- `data/raw/spots/`: 다섯 권역 및 도심 구성 구역의 실제 CSV와 수집 메타데이터.
- `data/raw/`: 기존 동성로 CSV 및 교통 자료.
- `data/reports/상권보고서.pdf`: 현재 출처정보 추가판 10쪽과 대응 메타데이터.
- `db/portable_vectors.json.gz`: 기존 GMS 벡터와 키 없는 실행용 로컬 벡터.
- `db/inventory.json`: 제출본의 벡터 구성 기록.
- `db/runtime/<해시>/chroma_db/`: 자동 복원된 실제 ChromaDB.

사용하지 않는 과거 개별 상가 색인 8,496개는 제외하고 실제 검색에 필요한 메타데이터 **1,452개와 PDF 14청크**를 각 백엔드에 담았습니다. 저장량은 메타데이터 2,904개·PDF 28개이며, 한 번의 검색은 선택된 모델의 1,452/14개만 사용합니다. 개발 환경의 전체 9,948개 기록과 제출본 저장량은 다릅니다.

GMS 임베딩은 `text-embedding-3-small`, 로컬 임베딩은 문자 n-gram입니다. 둘은 학습 방식이 다르며 검색 결과가 동일하다고 주장하지 않습니다. 모델·자료 버전 필터로 혼합을 방지합니다. ZIP 추출 시 수정시각이 바뀌어도 내용이 같으면 벡터를 사용할 수 있도록 콘텐츠 해시 기반 버전을 사용합니다.

첫 실행에 포함 벡터를 `db/runtime/<해시>/chroma_db`로 자동 복원합니다. Windows 프로젝트 경로에 한글이 포함된 경우에만 실행용 DB를 임시 폴더의 `spotcheck_vectors`에 생성합니다. 이미 계산된 벡터를 옮기는 작업이며 외부 호출·임베딩 재생성이 아닙니다. 최초 실행에서 별도 색인 명령을 실행할 필요가 없습니다.

새 자료를 수집하거나 PDF·청킹·임베딩 모델을 바꾸는 개발 작업에만 아래 명령을 사용합니다.

```powershell
# 신규 수집 시 본인 API 키 필요
.venv\Scripts\python.exe src/collectors/collect_spot_stores.py --spot all --refresh
# 자료/설정을 바꾼 경우에만 재색인
.venv\Scripts\python.exe scripts/prepare_rag.py
```

자료 변경 후에는 선택한 백엔드에서 새 버전으로 색인해야 합니다. 이는 최초 사용자의 실행 절차가 아닙니다.

## 출처와 이용 조건

| 자료 | 출처·기준 |
|---|---|
| 상가 CSV | 소상공인시장진흥공단 공공데이터 API의 수집 시점 등록 정보 |
| 상권 통계 | 소상공인365 사용자 직접 수집. 유동인구·매출·주거인구·업소 2026-07, 직장인구·소득·소비 2026-06 |
| 상권 PDF | SPOT CHECK 자체 제작, 설명문에 ChatGPT 활용. 출처정보 추가판 |
| 지도 | 네이버 Maps 또는 Streamlit 기본 지도 |

공식 API 이용허락 증빙과 소상공인365 통계·이미지의 재이용/재배포 조건은 최종 확인 사항입니다. PDF의 자체 제작 표기가 포함 원천 자료의 이용 조건을 대체하지 않습니다. 요청한 프로젝트 평가·실행 자료를 동봉한 것이며 공개 재배포 허가를 확인했다는 뜻은 아닙니다.

API 수집 반경과 PDF 경계는 다릅니다. 도심 세 PDF 통계는 합산하지 않으며, PDF 지표를 주소 100m 통계로 환산하지 않습니다. 미확인 현재 위치·주소·범위 밖 전체 수·실시간 임대료·창업 성공률·개별 점포 추천은 추측하지 않습니다.
