# 요구사항 정의서

**프로젝트명:** SPOT CHECK  
**주제:** 소상공인 상권·입지 분석 RAG 챗봇

제출 구조 안내: 프로젝트 전체에 실제 CSV·PDF와 실행용 벡터를 포함한다. 아래 기존 8,496/9,948개는 개발 단계의 보존 색인 기록이며, 제출판은 활성 메타데이터 1,452개와 PDF 14청크를 로컬/GMS별로 담아 저장량이 2,904/28개다. 키 없이 로컬 검색·계산을 실행할 수 있고, 본인 GMS 키를 설정하면 GPT-6 Luna로 동작한다. 별도 `output/구현소스` 중복본은 두지 않는다.

## 1. 필수 기능 및 심화 기능 요구사항 정리

### 1.1 필수 기능

SSAFY AI 코어 프로젝트 2회차의 필수 기능 F2001~F2012를 기준으로 개발하였다.

| 구분 | 요구사항 ID | 주요 내용 |
|---|---|---|
| RAG 1 | F2001~F2002 | 상권 메타데이터 적재 및 벡터 DB 색인 |
| RAG 2 | F2003~F2005 | 검색어 추출, 외부 문서 수집·선별 및 색인 |
| 답변 생성 | F2006~F2008 | 검색 결과 병합, 근거 기반 답변 생성 및 출처 표시 |
| 서비스 기능 | F2009~F2012 | 지역 선택, 대화 관리, 조건 검색, 진행 상태 안내 |

### 1.2 심화 기능

| ID | 기능 | 선택 여부 |
|---|---|---|
| F2013 | 프론트엔드 UI 직접 구현 | 미선택 |
| F2014 | MMR 검색 적용 | 미선택 |
| F2015 | RAG 적용 전후 답변 품질 비교 | **선택** |
| F2016 | 여러 문서 출처 결합 | 미선택 |

**F2015 선택 이유:** 상권 분석 답변은 실제 통계와 점포 정보에 근거해야 한다. RAG를 사용하지 않았을 때와 사용했을 때의 답변을 비교해, 검색된 자료가 답변의 정확성과 출처 제시에 어떤 차이를 만드는지 확인하고자 선택하였다.

## 3. 선택한 도메인과 조건 충족 근거

### 3.1 도메인 및 데이터 규모

**선택 도메인:** 소상공인 상권·입지 분석

| 항목 | 확보 내용 |
|---|---|
| 상가정보 | 8,496건 |
| 지역·업종 데이터 | 1,452건 |
| 총 색인 대상 | 9,948레코드 |
| 외부 설명 문서 | 소상공인365 통계를 바탕으로 직접 제작한 상권 분석 PDF |

항목 메타데이터 100건 이상이라는 조건은 상가정보 8,496건으로 충족한다. 총 9,948건은 서로 다른 종류의 레코드를 합한 수로, 고유 점포 수를 뜻하지 않는다.

### 3.2 문서 출처와 이용 조건

| 자료 | 출처 및 작성 방법 | 이용 조건 |
|---|---|---|
| 상가(상권)정보 | 소상공인시장진흥공단 공공데이터 API | 보고서에는 무료·이용허락범위 제한 없음으로 기재. 공식 제공 페이지 확인 증빙은 최종 보완 필요 |
| 상권 통계 | 소상공인365 상권분석 지도에서 직접 조회 | 서비스 통계의 재이용·재배포 조건은 별도 확인 필요 |
| 상권 분석 PDF | 수집한 소상공인365 수치와 ChatGPT를 활용한 설명문으로 자체 작성 | 자체 제작 문서. 포함된 원천 통계에는 원자료의 이용 조건 적용 |

**통계 기준월**

- 2026년 7월: 상가업소, 유동인구, 매출, 주거인구
- 2026년 6월: 직장인구, 소득·소비

| 질문 | 필요한 자료 |
|---|---|

| 현재 자료로 실시간 임대료를 확인할 수 있나요? | 데이터 보유 여부 및 기준 시점 |

※ 이 문서는 기능 적용 내역을 정리한 요구사항 정의서이며, 검증 결과는 별도로 관리한다.


## 4. 현재 구현 범위와 검증 기준

- 지원 지역: 대구 도심 통합상권(동성로·대구역·반월당), 수성못, 삼덕동, 동대구역, 칠곡3지구.
- 전체 저장 9,948레코드 중 현재 버전 검색 대상은 지역·업종 메타데이터 1,452개이며 기존 상가 문서 8,496개는 보존 상태다. PDF 검색 대상은 14청크다.
- 질문마다 외부 API를 새로 수집하지 않고 기수집 CSV와 지정 PDF를 사용한다. Python이 전체 CSV의 좌표·업종을 계산하고 GPT는 검색 원문을 선택·검증하는 데 사용한다.
- 검색어 생성·PDF 후보 평가 후 선정 문서만 색인 확인/추가하고 PDF 벡터 검색을 선정 ID로 제한한다. 지역 설명은 필수 보존한다. 생성 검색어로 웹/API를 실시간 재수집하는 기능은 기본 서비스 범위에 포함하지 않는다.
- PDF 경계와 API 수집 반경은 다르며 도심 세 PDF 통계는 합산하지 않는다. 현재 위치·미확인 주소·수집 범위 밖 전체 수·실시간 임대료·창업 성공률·개별 점포 추천은 추측하지 않는다.
- 사용자 메시지는 오른쪽에 먼저 표시하고 왼쪽에서 AI 로딩 후 답변을 제공한다. 대화는 현재 세션 내 관리이며 영구 보관을 보장하지 않는다.
- 회귀 74개 통과. 실제 Luna 5문항 결과와 부분 실패, 통제 환경 검사 및 미확인 항목은 검증결과에 기록했다. 상호 검토는 사용자 확인 기준 미실시다.
- 통계·이미지의 재배포 허용, 새 환경 재현, 부하·사용성 기준과 최종 제출자 정보는 추가 확인이 필요하다.
