# 데이터 출처 기록

## 상가(상권)정보
- 제공기관: 소상공인시장진흥공단
- API: https://apis.data.go.kr/B553077/api/open/sdsc2/storeListInRadius
- 수집일: 지역별 `data/raw/spots/<region_id>/metadata.json`의 `collected_at_utc` 및 `source_date_range` 참조. 옛 동성로 원본은 `data/raw/collection_metadata.json`
- 범위: 대구 도심 통합상권/수성못/삼덕동/동대구역/칠곡3지구의 각 수집 범위. 도심은 세 원의 상가 ID 합집합. 공식 PDF 상권 경계와 다름
- 이용 조건: 공공데이터포털 해당 데이터 상세페이지에서 확인 후 기록
- 공식 확인 대상: https://www.data.go.kr/data/15012005/openapi.do . 2026-10-22 재확인 시 상세페이지 조회 실패/기본 페이지 반환으로 이용허락 문구를 직접 확보하지 못했다. 검색 결과나 제3자 재게시만으로 '제한 없음'을 확정하지 않는다. 평가·공개 배포 전에 공식 화면의 실제 이용허락 조건 확인이 남는다.

## 현재 채팅 지정 PDF

- 파일: `data/reports/상권보고서.pdf`, 사용자 제공 개정판 10쪽. 존재하지 않는 공개 URL을 만들지 않음
- 2026-10-23 사용자 제공 「상권보고서_출처정보추가.pdf」로 교체했다. 10쪽에 자료 출처·이용 조건·자체 제작 및 ChatGPT 활용·RAG 활용 목적이 추가됐다. 보고서에 적힌 API 이용허락 설명은 문서 작성자의 기재이며, 공식 조건의 독립 확인 결과와 구분한다. 교체 전 보관본은 정리 시 `.archive`로 이동했으며 제출 ZIP에는 넣지 않는다.
- 원문 출처/범위: 사용자 제공 자료. 기초 통계/정의는 원문 1·2·10쪽, 지역 설명은 3~9쪽. 원천기관 통계를 새로 실측하거나 검증한 것으로 표현하지 않음
- 기준월: 유동인구·매출·주거인구·업소 2026-07, 직장인구·소득·소비 2026-06
- 수집일: 제공 메타데이터에 미기록. 기준월을 수집일로 바꿔 표기하지 않음
- 이용 조건: 프로젝트 내부 분석과 GMS 전송은 사용자 승인. 공개 재배포 허용이나 기초 출처의 이용 조건을 임의 확정하지 않음
- 색인: 실제 `external_documents` 14청크. 각 청크에 파일명·지역·페이지·기준월·usage_note 기록
- `active_report.source.json`은 보고서 등록 당시 원문/해시/기준월 기록이다. 현재 운영 색인 상태는 실 DB 및 `data/processed/rag_inventory.json`으로 확인한다

## 보관 중인 다른 보고서와 웹 수집

`data/reports/latest_report_manifest.json`에 확보/이용조건 상태를 기록한다. 활성 자료로 자동 편입하지 않는다. 웹 수집기는 원 URL·제공기관·수집일·본문 해시·robots 및 이용조건 메모를 저장한다. Tavily 실호출은 키 부재로 미검증이며, 이 작업에서 새 발행기관 자료를 임의 추가하지 않았다.
