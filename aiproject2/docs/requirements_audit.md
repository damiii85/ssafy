## 심화 기능

- F2016: 선택하지 않음. API 메타데이터와 사용자 PDF를 실제 각 컬렉션에 색인·결합하고 출처 유형을 구분하지만, 이를 여러 외부 문서 출처 색인 완료로 확정하지 않는다.
- F2013: Streamlit 유지. 별도 프론트엔드/서버 분리 조건 충족으로 표시하지 않는다.
- F2014: MMR 미구현. 기존 유사도 검색 유지.
- F2015: 선택·실행 완료. 동일 GMS 모델로 대표 5질문의 무검색 응답과 실제 서비스 응답을 확보하고, 자료와의 일치·근거 제시·미확인 정보 처리로 비교했다. `rag_quality_comparison.md` 및 `evidence/rag_quality_comparison.json` 참조. CSV/PDF 처리까지 포함한 서비스 비교이며 검색만의 인과 효과나 모든 문항의 성능 향상을 주장하지 않는다.

## 원문 대조 후 남은 확인

- F2004는 정의서 13쪽의 제공 문서 묶음 대체 허용 조항에 따라 지정 PDF를 사용한다. Tavily 실호출을 필수 요구로 추가하지 않는다.
- NF2001 실모델 새 비교 실행은 일반 답변 약 10.8~16.3초였다. 사용성 판정과 동시 부하까지 완료했다고 보지 않는다.
- 기존 venv와 달리 별도 `.venv`는 요구서 필수 버전 14개가 모두 일치한다. `requirements.txt`와 `dependency_versions.md`에 기록했다. Streamlit 1.62 차트 설명·컴포넌트 등록 호환성을 수정하고 지정 환경 72개 회귀 및 실제 GMS 검색·모델 호출을 검증했다. 다른 교육생의 환경 검토를 대신한 것은 아니다.
- 제출 전 상호 검토는 사용자가 미실시라고 확인했다. 데이터 이용 조건과 새 환경 재현은 체크리스트의 미확인 상태를 유지한다.

최종 실행 증거는 `docs/rag_test_results.md`, 설계는 `docs/rag_pipeline.md`, 점검표는 `output/submission_checklist.md` 참조.
