## API 통합과 중심점

도심 원본 세 개의 23,785행에서 상가 ID 기준 13,026개 중복 행을 제거해 10,759곳을 저장했다. 같은 ID의 정보가 다르면 수집일이 최신인 행을 먼저 사용한다. 원본 수집일 범위를 보존하며 통합 생성일을 새 API 수집일인 것처럼 표시하지 않는다.

- 도심 대표 기준점: 기존 동성로 중심 35.870 / 128.595.
- 대구역 기준점: 대구역앞 정류장 DGB7001010600, 35.87459 / 128.59762.
- 반월당 기준점: 2호선반월당역1 정류장 DGB7001001400, 35.86526 / 128.59562.
- 삼덕동 기준점: 경북대학교병원앞 정류장 DGB7001009800, 35.86523 / 128.60325.
- 동대구역 중심: 기존 프로젝트 설정 복원, 35.879 / 128.628.
- 칠곡3지구 중심: 기존 프로젝트 설정 복원, 35.943 / 128.563.
- 수성못 중심: 기존 프로젝트 설정, 35.828 / 128.617.

정류장 자료는 기존 대구BIS 원본의 정보수집일 2025-10-31 기준이다. 이 좌표들은 파일럿 수집 기준이며 상권·역의 정확한 경계나 추천 매물 위치가 아니다. 세 도심 구성 지역의 원본은 통합 재생성과 세부 기준점 질문용으로 보존하되 별도 최상위 카테고리로 표시하지 않는다.

## 거리 질문

`src/services/distance_scope.py`가 질문의 반경을 읽고 실제 위경도 거리로 필터링한다. `100m`, `100 미터`, `0.1km`를 같은 100m로 처리한다. 0·음수·복수 반경은 명확히 재입력을 안내한다.

- 기본: 선택한 권역의 전체 수집 범위. 도심은 세 수집 원의 합집합.
- '100m 이내 카페': 해당 권역의 대표 기준점 반경 100m.
- '반월당 100m 카페': 통합권역 안의 반월당 수집 기준점 반경 100m.
- '50m 유사 업계는?': 직전 업종과 세부 지역 기준점을 유지하고 50m로 재계산.
- '전체 범위 현황': 거리 필터를 해제한다. 세부 지역에서 통합 전체로 돌아가려면 '대구 도심 통합상권 전체 범위'라고 지정한다.
- 위치를 모르는 '내 위치 100m'는 임의의 고객 위치로 계산하지 않는다.
- 요청 원 전체가 수집 원 안에 들어가지 않으면 정확한 전체 점포 수를 알 수 없다고 안내한다. 2km를 1km나 200m로 조용히 대체하지 않는다.
- PDF 통계는 지정 상권의 값이므로 100m 유동인구·매출 등으로 환산하지 않는다.

현재 도심 대표 기준점의 실제 카페 수는 100m 19곳(전체 상가 271곳), 200m 42곳(전체 636곳)이다. 수집 시점의 값이며 다른 기준점·PDF 경계에는 전용하지 않는다.

수집: `python src/collectors/collect_spot_stores.py --spot all` (기존 수집본 재사용, `--refresh`로 갱신).
가공: `python -m src.services.spot_summary`.
검증: `python -m unittest discover -s tests -v`.
