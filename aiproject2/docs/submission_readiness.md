# 최종 제출 준비 상태

기준: 사용자 제공 「AI코어프로젝트_2회차_요구사항정의서.pdf」 9~19·21~23쪽, 2026-10-22.

## 제출 범위

- 필수 F2001~F2012: 구현·실행 증빙을 요구사항 대조표에 연결한다. 자연어 탐색은 지원 지역·업종·등록 점포 수 조건에 한정되며 자유로운 모든 조건의 이해를 보장하지 않는다.
- 선택 심화: **F2015 RAG 전후 품질 비교**. 같은 GMS 모델로 대표 질문 5개의 무검색 답변과 실제 RAG 서비스 답변을 기록한다. 결과는 `rag_quality_comparison.md`에 실제 실행 후 작성한다.
- F2013 화면/서버 분리와 F2014 MMR은 선택하지 않았다. F2016은 API 메타데이터+PDF 결합만으로 여러 외부 문서 출처를 색인한 것으로 확정하지 않는다.
- F2004: 정의서 13쪽은 외부 호출이 제한되는 환경에서 제공 문서 묶음으로 수집 단계를 대체하는 것을 허용한다. 현재 지정 PDF 모드를 사용하며, Tavily 신규 웹 실수집은 필수 충족 증빙으로 주장하지 않는다.
- F2008: 간단한 기본 출처 목록과 접힌 상세 출처를 함께 제공한다. 숨긴 상세 정보도 근거 번호·실제 문서·URL/페이지 연결을 보존한다.

## 실행 환경과 재현

기존 `venv`는 보존하고 별도 `.venv`에 요구서의 필수 버전 14개를 정확히 설치했다. Streamlit 1.62의 차트 설명 인자·컴포넌트 등록 호환성을 보완했고 이 환경에서도 72개 회귀 검사, pip check, 실제 GMS 검색·모델 호출을 확인했다. `requirements.txt` 하나에 필수 버전과 실제 검증한 Windows/Python 3.11 환경 전체의 의존성을 고정했다. `dependency_versions.md`와 `evidence/spec_environment.json`에 기록한다. 다른 운영체제에서 같은 설치를 보장하는 범용 잠금 파일은 아니다. 브라우저 검사 도구 Playwright/Edge는 기존 개발 환경에서 별도 사용했다.

```bash
python -m venv .venv
# Git Bash
source .venv/Scripts/activate
python -m pip install -r requirements.txt
cp .env.example .env
cp config/rag_settings.example.json config/rag_settings.json
```

`.env`에 본인의 키를 설정하고 README의 데이터 준비·색인 절차를 따른다. 외부 처리를 허용한 경우에만 GMS 설정을 활성화하고 재색인한다. 키·CSV·원문 PDF·실제 DB·질문 캐시는 코드 ZIP에 넣지 않는다. 원문 자료는 권한을 확인한 제출 경로로 별도 준비해야 한다. 코드 ZIP만으로 데이터가 자동 복원되는 것은 아니다.

## 사람이 마무리해야 하는 항목

- **상호 검토 미완료**: 사용자가 아직 진행하지 않았다고 확인했다. 옆 교육생의 검토자·일시·실제 결과를 `output/submission_checklist.md`에 기록한다. AI 검사 결과로 대체하지 않는다.
- **자료 이용 조건**: 사용자 제공 PDF와 이미지의 프로젝트 사용과 공개 재배포 허용을 구분한다. 공개 배포/원문 재배포 허가는 확인되지 않았다. 공공 API 이용조건도 공식 상세페이지에서 최종 확인한다. 제출 ZIP은 원문 PDF/CSV/미사용 관광 사진을 제외한다.
- **제출자 정보**: 실제 지역·반·성명을 확인해 정의서 23쪽 형식으로 ZIP 파일명을 바꾼다. 현재 이름은 임시 제출 파일명이다.
- **새 환경 실행**: 데이터·키·지도 도메인 설정을 준비한 다른 교육생의 환경에서 실행 확인이 필요하다. 현재 환경 검사만으로 완료 표시하지 않는다.

동시 접속 부하와 공개 운영 보안 심사는 별도다. 제출 준비가 완료되었다는 표현을 공식 평가 통과·배포 완료·상호 검토 완료로 해석하지 않는다.
