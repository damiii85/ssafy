# 보고서 근거 관리

채팅의 지정 자료는 이 폴더의 `상권보고서.pdf`(개정판 10쪽)다. 종전 지정 보고서 파일은 삭제했다. 사용자 제공 자료로 취급하며 공식 원천 데이터를 새로 검증한 문서라고 표현하지 않는다.

활성 자료 메타데이터: `active_report.source.json` (SHA-256, 페이지 매핑, 기준연월, 경계 한계).

도심 3~5쪽, 수성못 6쪽, 삼덕동 7쪽, 동대구역 8쪽, 칠곡3지구 9쪽. 통계표 2쪽, 기준·한계 1·10쪽을 함께 읽는다. 도심 세부 구역 PDF 수치는 합산하지 않는다.

다른 기관의 보관 보고서는 `LATEST_REPORTS.md`와 `latest_report_manifest.json`에 확보 상태를 기록하며 채팅 근거에 자동으로 병합하지 않는다. PDF는 Git 제외이므로 별도 배포가 필요하다.
