# 05-pjt | 댓글 증강 시스템

회사명을 입력하면 토스증권 커뮤니티 댓글을 실시간으로 수집하고, 정제·필터링·증강 결과를 확인할 수 있는 Django 웹 서비스입니다.

- **수집:** Selenium으로 검색 결과 최상단 종목의 댓글 20개 수집
- **전처리:** 결측치·이모티콘·특수문자를 정리하고, 길이 5~76자의 댓글만 유지
- **필터·증강:** GMS LLM으로 부적절한 댓글을 제거하고 의미를 유지한 문장 생성
- **주가·감성분석:** 수집 시점 전일 대비 등락을 색상으로 표시하고, 원본 댓글을 요약하여 긍정·부정·중립 비율과 판단 이유 제공
- **결과 확인:** 원본·정제·증강·통합 데이터를 웹 화면에 표시하고 처리 결과를 DB에 저장

**사용 기술:** Python, Django, Selenium, pandas, GMS LLM API

프로젝트 결과물은 [output](output/) 폴더에 있으며, 실행 화면 캡처는 [output/capture](output/capture/)에서 확인할 수 있습니다.
